jev Box PoC — 画像内オブジェクトの座標検出デモ

TypeSafe AI「System One」モデル jev の Box（バウンディングボックス）を試すデモです。画像をアップロードし、探したい対象を自由入力して送信すると、座標を数値表示し、画像上に矩形を描画します。

本日の利用状況: —

1. 画像とプロンプト

クリック または ドラッグ&ドロップ
jev制限: 256〜1568px。超える場合は自動縮小します
23 画像内の数字 23 左上の数字 the number in the image
jev の Box は 1回につき 1つの対象の座標を返します。別の対象を試すときはプロンプトを変えて再送信してください。
翻訳ボタンは、日本語なら英語へ・英語なら日本語へ変換して入力欄に反映します。

2. 結果（座標の数値 + 矩形描画）

画像をアップロードすると、ここにプレビューと検出結果が表示されます。
confidence（確信度 0〜1）
jev との通信ログ（送信・受信・レイテンシ）
